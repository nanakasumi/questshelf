# QuestShelf

QuestShelf is a web application built with Vue.js that allows users to discover games and manage their personal game library.

## Features

- Browse a game catalog
- Search games by title
- Filter games by genre
- Add and remove games from your personal library
- Organize games by status: Playing, Completed and Backlog
- Mark games as favorites
- Track ratings and hours played
- Add personal notes to games
- Automatically save library data using localStorage

## Tech Stack

- Vue.js
- JavaScript
- HTML5
- CSS3
- Vue Router
- Vitest

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd questshelf
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

## Testing

The project includes unit tests for the library functionality, including adding, removing and managing games, as well as local storage persistence.

Run the tests with:

```bash
npm run test
```
